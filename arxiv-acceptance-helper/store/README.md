# Chrome Web Store assets

`promo-440x280.png` is a promotional image, not a screenshot. It was generated
with the built-in ImageGen tool using the existing PaperGlint icon as a reference,
then resized to 440×280. It is not included in the extension ZIP.

Prompt: Create a Chrome Web Store small promotional image, landscape aspect ratio
11:7. Reuse exactly the supplied ivory paper with amber glint symbol, prominently
centered at modest scale with generous negative space on a uniform deep petrol
teal background. Clean flat background without texture or shadows. No text, no
mockup, no new symbols. Preserve the identity of the supplied symbol.

Before submission, capture at least one real Chrome screenshot at 1280×800 or
640×400. Do not substitute generated imagery for the actual extension UI.
